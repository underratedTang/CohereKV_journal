NPC 2026 EXPERIMENT PACKAGE VALIDATION
======================================

Package purpose
---------------
- Preserve the existing PPL and LongBench evaluation paths.
- Add empirical-motivation, certificate-correctness, component-ablation,
  compression-core microbenchmark, profiler, memory-accounting and result-
  summarization utilities for the NPC 2026 paper.
- Keep CentroidKV, KeepKV, SimCalKV, CaM and GroupLogitKV implementations unchanged.

Method diagnostics added
------------------------
- nearest-feasible versus nearest-then-certify routing ablation
- exact complete-group diameter and violation analysis
- explicit multiround original-member tracking
- accepted entry and accepted count-mass ratios
- rejected count mass
- group-size and certificate-ratio diagnostics
- optional PPL JSONL diagnostics, disabled by default to avoid synchronization
- compression-only latency, pair throughput and peak temporary memory
- persistent KV, method side information and compression peak-extra memory

Limitations of this validation environment
------------------------------------------
No CUDA GPU, model weights, Hugging Face datasets or LongBench data were
available for full empirical runs. Therefore this report does not claim actual
PPL, LongBench accuracy, GPU latency, throughput or memory results. Those must
be generated with the supplied run scripts on the target hardware.
