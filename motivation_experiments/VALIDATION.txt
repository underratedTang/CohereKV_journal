Star-structure motivation pre-experiment package validation (v6)

Design changes:
- Panel (a) keeps the same semantics: group-level star-conflict prevalence vs retained KV budget.
- Panel (b) is replaced by pooled pair-level conflict rate:
    conflict_pair_rate = total conflicting same-anchor leaf pairs / total same-anchor leaf pairs.
- Panel (b) is NOT conditioned on star-conflicted groups and does NOT average per-group conflict densities.
  This removes the size-2-group artifact where one conflict would mechanically imply 100% group density.
- Panels (a) and (b) both support the same cosine-threshold sweep (default 0.70 / 0.80 / 0.90).
- Final figures depend only on summary_overall.csv + run_config.json, so existing real 3-sequence outputs can be redrawn without rerunning the model or requiring raw NPZ compatibility.
- No stacked bars or hatches are used; both panels use color + line style + marker and remain grayscale-identifiable.
- Horizontal combined (a)+(b) paper figure is generated.
- figure_statistics.csv records exact group-level and pair-level plotted percentages plus source counts.
- summary_overall arithmetic is validated from source counts before plotting.
- Default MAX_EVAL_SEQUENCES remains 3.
