MYMETHOD D2O-STYLE SELECTOR PACKAGE VALIDATION
Date: 2026-08-08

Scope
- Added selector="d2o" only for retained/evicted partitioning.
- Kept all post-partition operations in mymethod: compatible routing, Gamma certificate,
  conflict graph, parallel maximal independent set, count-weighted K/V merge, C/R/D
  propagation, and +log(C) decode calibration.
- No CUDA kernel changes.

D2O-style selector semantics
- Request-level persistent cumulative post-softmax attention per physical KV head.
- GQA query heads sharing a KV head are averaged before query-row accumulation.
- D2O_USE_LOG_COUNT=1 accumulates the actual +log(C)-calibrated attention used by mymethod.
- Sink size and recent size are independently configurable D2O-only parameters.
- Sink entries consume the heavy-hitter budget; recent entries are protected separately.
- Sink/recent retained entries may absorb candidates only through mymethod certification.
- After compression, cumulative importance is gathered to retained anchors only; evicted
  source history is not transferred to destinations.
- D2O cosine routing, EMA similarity threshold, weighted merging, and layer allocation are absent.

Selector namespaces
- attention: no sink/recent/history parameters.
- keepkv: KEEP_KV-specific sink, recent-protect, score-window, beta, absorb controls.
- d2o: D2O-specific sink, recent, absorb, log-count controls.
- No legacy shared MYMETHOD_SINK_SIZE / MYMETHOD_RECENT_WINDOW / MYMETHOD_RECENCY_BETA /
  MYMETHOD_SINK_CAN_ABSORB shell or CLI parameters remain.
