REAL-KV OFFLINE SMOKE DIAGNOSTIC
Reused a previously captured uncompressed Llama-3.2-3B WikiText-2 KV snapshot
(length 2048; layers 0/14/27) only for geometry checks.
At compression ratio 0.4 and lambda=0.5, graph-MIS accepted 21.87%, 36.25% and
22.07% of evicted entries in layers 0/14/27. Anchor-only grouping produced
8.62%, 12.37% and 10.55% exact complete-group violations, while full graph-MIS
produced zero. At lambda=0.75, full acceptance rose to 76.95%, 94.58%, 85.84%
with zero exact first-round violations.
For routed pools of size <=14, an exact maximum-independent-set diagnostic on
up to 200 pools/layer/lambda found the degree-priority maximal MIS reached
maximum cardinality in 98.5%-100% of sampled pools; worst observed gap was one
candidate.
These are geometry-only reuse results, not new PPL/LongBench results.

PERFORMANCE VALIDATION LIMITS
- Current environment has no CUDA model benchmark run for the new graph-MIS
  method. CPU benchmark is only a code-path smoke test and is not paper data.
- No new PPL or LongBench values were generated for graph-MIS in this container.
- The current eager implementation is parallel at the tensor level but not
  fully fused. Main engineering risks are padded local conflict matrices,
  O(sum m_j^2 d) candidate-candidate work, one max-pool host synchronization,
  and fixed max-pool MIS device iterations.
