Runtime decoupling validation
=============================

Changes:
- CentroidKV no longer imports/applies GroupLogitKV runtime.
- CentroidKV uses SDPA automatically when the caller leaves the legacy eager default.
- GroupLogitKV remains available and keeps its own runtime patch.
- SimCalKV/CaM use neutral reduced-attention capture runtimes.
- LongBench setup imports only the selected method implementation.
- PPL and system evaluators use the same isolation policy.

Validation performed in packaging environment:
- python -m compileall -q . : PASS
- python -m unittest discover -s tests -p 'test*.py' -v : 46 tests PASS
- bash -n for every top-level .sh : PASS
- neutral score-capture runtimes contain no GroupLogitKV/calibrated-QK imports : PASS
- static dispatcher test verifies CentroidKV branch contains no GroupLogitKV runtime dependency : PASS

Environment limitation:
- A full Qwen/LongBench GPU run was not executed in the packaging container because the full evaluation Python dependencies/model weights are not installed there. The user-side environment should rerun the previously failing CentroidKV LongBench command and confirm the log reports the eager -> sdpa override.
